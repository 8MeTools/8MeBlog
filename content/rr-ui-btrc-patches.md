# 【特別編】BTRCで変更したボタンカラーを`Patches`を利用して適用しよう
最終更新日: 2026年5月19日

BTRCで変更したボタンカラーを`Patches`を利用して適用方法について説明します。

## はじめに
`Patches`の詳細情報は、[こちら](https://8metools.github.io/8MeBlog/?page=rr-ui-patches)を参照してください。

## 用途から採用すべき手法を選ぶ
`Patches`を利用した変更方法はいくつか用意されていますが、用途に応じて適切な手法を選択することが重要です。

結論、今回の場合は、ボタンやテキストカラーについて格納したファイルが複数存在するので、`Patches`の中でも「ファイル単位のオーバーライド(完全な上書き)」と「圧縮した差分アーカイブを使用する」手法を採用するのが適切です。とはいえ、2つの手法を組み合わせて利用することに困惑する方もいるかもしれません。各手法の特徴を理解して、適切に選択することが重要です。

| 手法 | 特徴 | 適用例 |
| --- | --- | --- |
| ファイル単位のオーバーライド(完全な上書き) |　変更内容が大きい場合や複数のファイルを変更する場合に適している | 従来のMKWiiに存在するUIファイル(`MenuSingle.szs`や`Race.szs`など) |
| 圧縮した差分アーカイブを使用する |　変更内容が比較的小さい場合や特定のファイルのみを変更する場合に適している | Mod(RR)側で用意されたUIファイル(`UIAssets.szs`や`RaceAssets.szs`など) |

要するに、ファイルに応じて適切な手法を選択する、いわば**ハイブリッドなアプローチ**が最も効果的であると言えます。変更内容の規模や影響範囲を考慮して、適切な手法を選択することが重要です。

> 今回は変更するサブファイルの数が多いため、サブファイル単位でパッチする手法(`[button][blyt]common_w004_menu.brlyt.menusingle`のように指定する方法)は適していません。

## BTRCのファイル生成を再確認する
BTRCで作成したファイルは、`EditedBRLYT`と`EditedBRLAN`の2種類に分かれています。これらの中には、以下のようなファイルが含まれています。

- `EditedBRLYT`：`.brlyt`ファイルが格納されているディレクトリ
- `EditedBRLAN`：`.brlan`ファイルが格納されているディレクトリ

これらのファイルは、BTRCで変更した内容を反映させるために必要なファイルです。これらのファイルを適切に管理し、`Patches`で使用するために準備することが重要です。

> 余談ではありますが、BTRCはこのアップデートに合わせ、生成時に`EditedBRLYT`と`EditedBRLAN`内のフォルダを一つに統合し、`Output`フォルダとしてファイルが格納されます。試験的に分離していましたが、利用傾向からこの判断に至りました。

## ファイルを移植
生成したファイルを移植する必要がありますが、「用途から採用すべき手法を選ぶ」で言及したように、圧縮する前に移植が必要なフォルダと不要なフォルダが存在します。

先に**移植が不要な**フォルダを説明します。`UIAssets.d`と`ReplacedAssets.d`です。BTRCで生成したものには、RR用であることを示すために`RRUIAssets.d`というフォルダが存在しています。各自で`UIAssets.d`にリネームしてください。

なぜなら、これらのフォルダに含まれるファイル数が少ない上、RR側のアプデ時にクラッシュする可能性を大いに軽減できるからです。

逆に言えば、これら以外のファイルは既存のSZSに移植が必要となるわけです。変更するファイル量が多いからです。

### フォルダの圧縮(wszst)

フォルダの圧縮は、以下のコマンドで実行できます。

```sh
wszst c FileName.d -o
```

`-o`は上書きを意味します。これにより、コマンド実行前に同一ディレクトリにあるSZSを削除することなくなり、上書きでファイルを生成することができます。

余談ではありますが、同一ディレクトリの中で複数のフォルダを圧縮したい場合、以下のようなコマンドが便利です。

```sh
wszst c *.d -o
```

実行すると分かりますが、一度に複数のSZSを生成できてしまいます。便利ですよね。

### SZSのファイル名の変更
現状、`Patches`システムで適用するには以下のようなルールがあります。

- `MenuSingle`や`Race`など、既存のSZSに関してはその名前のまま`Patches`フォルダに入れておく
- `UIAssets`や`ReplaceAssets`など、RR(Pulsar)側で追加されたSZSに関しては所定の命名規則に沿った名前で`Patches`フォルダに入れておく

というわけで、`UIAssets.szs`と`ReplacedAssets.szs`のファイル名を以下のように変更してあげましょう。
```
yourmodname.uiassets.szs
```

```
yourmodname.replacedassets.szs
```

`yourmodname`の部分はお好きな名前でOKです。アルファベットで、分かりやすい名前でもつけておきましょう。

#### 注意
言語設定を**英語以外**に設定している場合、UIAssetsの差分が読み込まれません。

ここでは、日本語設定の場合の対処法を書いておきます。

```
yourmodname.uiassets_j.szs
```

`uiassets`の文字列の後ろに`_j`を追加しました。これで、読み込まれるようになるはずです。
